# Add `code:grill` + `pr:grill` In Caveman Voice

## Summary

Add 2 new skills:

- `plugins/code/skills/grill/SKILL.md`
- `plugins/pr/skills/grill/SKILL.md`

Both skill files use caveman-ultra prose, not normal repo prose.

No hook/runtime work. No sticky mode. No publish/write side effects during grill except optional recap artifact after explicit user yes.

## Key Changes

- `code:grill`
  - Default src: current local diff.
  - Also accept: pasted code, file, `path:line`, `path:start-end`, symbol.
  - Mode: no-edit, interactive, 1 q at time, adaptive layers.
  - Coverage map explicit in skill:
    - why change exist
    - behavior change
    - control/data flow
    - invariants
    - edge cases
    - tests/validation
    - tradeoffs
    - risk/regression
  - Exhaustive rule: cover all buckets; skip/compress only if user already proved bucket.
  - Answer rule:
    - correct: brief ack; no full key unless user asks
    - partial/wrong: cite local code, explain gap, ask 1 teach-back follow-up
  - Optional artifact:
    - `./.local/docs/code-grill/{branch-with-slashes-replaced}/{NNNN}_GRILL.md`
    - shape: study recap, not transcript

- `pr:grill`
  - Accept: PR URL/number, existing `BODY.md`/`NOTES.md`, current checked-out PR ctx.
  - Default src: reuse existing `pr:describe` artifact or run `pr:describe` flow first, then grill on artifact + diff + local code.
  - Coverage map explicit in skill:
    - PR why
    - reviewer ctx
    - changed behavior
    - key files/hunks
    - validations
    - tradeoffs
    - rollout risk
    - likely review questions
  - Hard rule: every assistant eval/correction/answer cite evidence.
    - Allowed evidence: PR metadata, `BODY.md`, `NOTES.md`, diff hunk refs, local code refs.
    - If evidence weak: say uncertain, inspect more, no guessing.
  - Correction loop: evidence-backed correction + 1 teach-back follow-up.
  - Optional artifact:
    - `.local/docs/pr-grill/{provider}_{pr-number}_{branch-name-normalized}/GRILL.md`
    - shape: study recap

- Manifest wiring
  - `plugins/code/.codex-plugin/plugin.json`
    - add capability `code-knowledge-grilling`
    - update descriptions
    - add `$code:grill` to `defaultPrompt`
  - `plugins/pr/.codex-plugin/plugin.json`
    - add capability `pull-request-grilling`
    - update descriptions
    - add `$pr:grill` to `defaultPrompt`
